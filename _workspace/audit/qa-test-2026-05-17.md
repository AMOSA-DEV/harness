- Codex CLI가 스킬 로딩과 설계 판단까지는 진행했지만, CLI 세션 resume은 현재 샌드박스에서 사용자 홈 Codex state DB 쓰기 제한으로 막혔다.

- 과거 감사 메모는 `_workspace/05_*`, `_workspace/06_*`, `_workspace/07_*` 루트 경로에 남아 있다. 현재 정책상 즉시 이동하지 않고 새 산출물부터 목적별 폴더를 사용한다.
